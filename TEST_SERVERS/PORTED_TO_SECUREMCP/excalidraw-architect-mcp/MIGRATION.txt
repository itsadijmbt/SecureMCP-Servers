excalidraw-architect-mcp: FastMCP -> SecureMCP
==============================================

Only src/excalidraw_mcp/server.py was edited.


CHANGES
-------

1. Import.
     was:  from fastmcp import FastMCP
     new:  from macaw_adapters.mcp import SecureMCP

2. Constructor + name kebab-casing.
     was:  mcp = FastMCP("Excalidraw Architect", instructions=...)
     new:  mcp = SecureMCP("excalidraw-architect")
   - `instructions=` is FastMCP-only; SecureMCP.__init__ doesn't accept
     it (would silently land in extra_config via **kwargs). Dropped.
   - Renamed "Excalidraw Architect" -> "excalidraw-architect".
     A space inside the SecureMCP name hangs `call_tool` for the full
     180s timeout (registration + list_tools still work; no server-side
     log). Verified empirically on this port; kebab-case fixed it.

3. Decorator call form (4 sites).
     was:  @mcp.tool
     new:  @mcp.tool()
   fastmcp 2.x supports the bare-decorator sugar. SecureMCP's `tool`
   (mcp.py:486) is a factory -- it only returns the decorator when
   called. Without the parens, none of the 4 tools register.

4. Entry-point docstring updated to reflect mesh transport.
   `main()` body is byte-identical: `mcp.run()`.

5. The 4 tool function bodies are UNCHANGED.
   create_diagram, mermaid_to_excalidraw, modify_diagram,
   get_diagram_info -- verified by `diff` against upstream.
