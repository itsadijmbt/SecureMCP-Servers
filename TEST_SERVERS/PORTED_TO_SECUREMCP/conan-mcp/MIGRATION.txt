WHAT
- conan_mcp/main.py only. FastMCP("conan-mcp") -> SecureMCP("conan-mcp").

  docstring. Upstream's own "Args:" text in those descriptions is unchanged.
- 7 list[str] parameters given the plain type list (filter_settings,
  filter_options, settings_host, options_host, requires x2, tool_requires).
  They were published as "string". Old type kept in "# was:".
